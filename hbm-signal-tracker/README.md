# HBM 核心逻辑跟踪看板

一个纯静态、无依赖的可交互看板，用于跟踪「HBM 核心逻辑失效【必须卖出】双大类信号清单」，辅助判断是否应该减持 / 清仓海力士、三星、美光。

## 信号体系

- **一、终极致命信号**（出现任意 1 条 → 长期清仓）：彻底推翻 HBM 刚需的技术路线颠覆信号，例如英伟达旗舰 GPU 取消绑定式 HBM、GDDR8 带宽反超、CPO 内置内存替代外置 HBM、国内厂商量产对标 HBM5 产品。
- **二、周期见顶信号**（出现任意 1 条 → 阶段性减持）：4 个领先指标，包括长协订单大规模取消、库存周数跳升至 12 周以上、合约价涨幅连续 2 个月低于 3%、原厂大幅上调资本开支。
- **三、假恐慌信号**（仅供参考，不用卖出）：柜内本地 SSD/SOCAMM 减配、特供版芯片改用 GDDR、单季度利润略低于预期。

勾选任意信号后，页面顶部的判定面板会自动更新为对应的操作建议（🚨 长期清仓 / ⚠️ 阶段性减持 / ✅ 继续持有）。勾选状态保存在浏览器 `localStorage`，刷新页面不会丢失，可点击「重置」清空。

## 使用方法

无需安装依赖，直接用浏览器打开 `index.html` 即可，或本地起一个静态服务器：

```bash
cd hbm-signal-tracker
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```
