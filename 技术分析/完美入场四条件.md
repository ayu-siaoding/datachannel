# 完美入场四条件

> 技术发现后 **不要急于下结论**；用 AI / 工具做第二层分析，四项全清晰才开新仓。

## 流程

```text
技术发现 → AI/工具六维分析 → 判断驱动类型 → 四条件齐全 → 开新仓
```

## 第二层：六类信息

| 维度 | 要点 |
|------|------|
| 基本面 | 营收、利润、负债、现金流 |
| 消息面 | 催化真伪、监管/减持/业绩雷 |
| 近一月资金流入 | 持续净流入 vs 单日脉冲 |
| 机构持仓 | 增配或稳定 |
| 市场研报 | 一致预期与核心假设 |
| 估值 | PE/PB/PEG 相对历史与同业 |

## 驱动类型

**情绪推动** · **业绩推动** · **产业拐点**（可组合；仅情绪则小资金降仓或只做短线）

## 开新仓公式

```text
技术信号 + 资金流入 + 估值合理 + 产业向上发展期
```

任一项不清晰 → **不开新仓，只观察**。

## AI 提问模板

```text
股票：{代码} {名称}
请基于公开信息分析：
1）基本面要点与主要风险

3）机构持仓变化（若有季报数据）
4）研报一致预期与估值是否合理
5）主导驱动是情绪/业绩/产业拐点中的哪一种？
6）是否同时满足：技术信号+资金流入+估值合理+产业向上？缺哪一项？
仅作研究参考，不构成投资建议。
```
