# 短线题材与盘前扫描（09:20）

> 方法参考：[X 视频帖](https://x.com/cj3214567667/status/2114717684827037856/video/1)  
> 实现：`scripts/premarket_scan.py --method short-theme`

## 适用范围

- 沪深主板 + 创业板 + 科创板；**排除北交所、ST**。
- 每个交易日 **09:20（Asia/Shanghai）** 跑观察池代码。

## 三指标

1. **溢价**：昨涨停 → 今竞价是否认账（核心 ≥3%，跟风高开≥7%后翻绿不追）  
2. **集中**：3 日同题梯队 + 放量，非单日脉冲  
3. **共识**：空间龙 → 中军 → 带板块补涨（同概念 ≥3 只跟涨）

## 核心原则

- **主线 ≠ 今日涨幅最大板块**（竞价最强单独列为「非主线参考」）  
- 放量突破只在 **龙/中军** 上有延续意义  
- **不在尾声**接棒（relay 模式连板 ≥6 不进观察池）  
- 分化回流：**空间龙 → 中军 → 补涨**

## 每日自动化

```bash
./scripts/daily_codes.sh
cat outputs/codes_$(date +%Y%m%d).txt
```

```cron
CRON_TZ=Asia/Shanghai

```

```bash
python3 scripts/premarket_scan.py --method short-theme --codes-only
MODE=dragon ./scripts/run_premarket.sh   # 龙头分歧回封
```
