# 小资金投机纪律

## 能力是什么

在 T+1、涨跌停下，用 **固定模式 + 严格仓位**，只做 **高共识、好位置、有溢价** 的少数机会，并拒绝尾声与杂毛。

## 投机能力分级（自检）

| 阶段 | 表现 |
| --- | --- |
| **L0** | 追涨停、听消息、无止损 → 靠运气，不算能力 |
| **L1** | 能按规则排除 ST/北交所/明显退潮，**少亏** |
| **L2** | 能识别**一条主线 + 2～3 个核心名**，只做溢价合格日 |
| **L3** | 分化日知道**先龙后中军**，跟风高开低走从不接 |
| **L4** | 月度回撤可控，**模式固定**，能写清「今天为何做/为何不做」 |

### 对照工具（你在哪一级）

| 阶段 | 盘前/盘中应做到的事 |
| --- | --- |
| L0→L1 | 用 [盘前Checklist](./盘前Checklist单页.md)；跑 `daily_codes.sh` 时**排除北交所/ST**；设单笔止损 |
| L1→L2 | 9:20 只记 **1 主题材 + 龙/中军/补涨**；昨涨停今核心 **竞价 ≥3%** 才接力（见 [短线题材](./短线题材与盘前扫描.md)） |
| L2→L3 | 分化日只盯 **空间龙 → 中军**；**高开 ≥7% 后翻绿** 的跟风一律不追 |
| L3→L4 | 固定 **relay 或 dragon 一种**；收盘写一句「做/不做及原因」；月度统计 **规则执行率** 而非只看盈亏 |

小资金现实目标：先稳 **L2～L3**，再谈放大资金；**L4** 是长期纪律，不是单日神操作。

## 建议仓位（可调）

- 单票：总资金 **15%～25%**
- 同一题材：**≤40%**
- 同时持仓：**1～2 只**
- 单日最大回撤：**约 -2% 账户** 停手
- 连亏 **2～3 笔** 按计划止损 → 减频或空仓

**L0～L1** 宜再降仓；**L3 以上** 仍不应超过上表上限。
