# 小资金投机纪律

## 能力是什么

在 T+1、涨跌停下，用 **固定模式 + 严格仓位**，只做 **高共识、好位置、有溢价** 的少数机会，并拒绝尾声与杂毛。

## 建议仓位（可调）

- 单票：总资金 **15%～25%**
- 同一题材：**≤40%**
- 同时持仓：**1～2 只**
- 单日最大回撤：**约 -2% 账户** 停手
- 连亏 **2～3 笔** 按计划止损 → 减频或空仓

## 能力分级（自检）

| 级别 | 表现 |
|------|------|
| L1 | 排除 ST/北交所/明显退潮，少亏 |
| L2 | 识别一条主线 + 2～3 核心名，只做溢价合格日 |
| L3 | 分化日先龙后中军，不救高开低走跟风 |
| L4 | 月度回撤可控，能写清「今日为何做/不做」 |
