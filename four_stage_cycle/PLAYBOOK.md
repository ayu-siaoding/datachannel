# Ted Zhang 四阶段市场周期框架

> 工具极简：周线 + 四条 SMA（10 / 20 / 30 / 40 周）。  
> 判断只看两样：**价格高低结构** + **均线排列与方向**。  
> 不构成投资建议。

---

## 0. 核心原则

| 原则 | 说明 |
|------|------|
| 周期 | **周线** — 打开任何品种（美股、A 股、黄金、比特币）都用同一套 |
| 均线 | SMA10 / SMA20 / SMA30 / SMA40，**30 周与 40 周是最关键判断线** |
| 阶段 | 任何时候必处于四阶段之一 |
| 唯一做多阶段 | **第二阶段** — 其他阶段要么观望，要么离场/做空 |

---

## 1. 第一阶段：筑底 → 观望

**特征**
- 大跌后价格不再创新低，均线缠绕，方向不明
- 坏消息很多，但价格「砸不下去」（如 FTX 爆雷时 BTC 见底）
- 可能持续 1–2 年震荡，最后还可能有大插针

**动作**
- **不要急抄底**
- 等明确转入第二阶段再考虑做多

**确认信号（向第二阶段过渡）**
- 底部**放量突破**
- 价格重新站上均线，均线开始多头排列

---

## 2. 第二阶段：上升 → 唯一适合做多

**必须同时满足**
1. 收盘价站在 **四条均线上方**
2. 均线标准多头排列：**10 > 20 > 30 > 40**，且四条线**均向上**
3. 价格结构：**更高的高点 + 更高的低点**
4. 常常**贴着十周线**往上走

**入场**
- 排列确认即可上车
- 可选：用 Claude / 研报深挖**基本面催化剂**（如 NVDA + ChatGPT、铀/核能 + AI 用电）

**持有**
- 中间回踩不用每天重新判断
- 只要排列没被破坏，就一直算第二阶段

**离场**
- 排列被破坏（见第三阶段）即下车

**案例：半导体 ETF（SMH）**
- 2020 疫情崩盘 → 第四阶段
- V 型反弹收复均线 → 短暂整理 → 均线多头排列 → **第二阶段确认**
- 随后贴着均线走了约两年；2021 年底开始在均线上连续被拒 → 进入第三阶段

---

## 3. 第三阶段：顶部震荡 → 减仓离场 / 考虑做空

**特征**
- 涨不动，在均线之间来回震荡
- 看起来像中继筑底，但**好消息托不住价格**（如财报超预期却跳空低开）
- 价格被压在十周线下，冲上去就被打回来

**动作**
- **多单减仓或清仓**
- 熟练后可按框架**做空**（如 Ted 在财报跳空那周进场）

**五八法则（龙头见顶）**
- 领涨龙头见顶后：约 **50% 概率跌 80%**，约 **80% 概率跌 50%**
- 人人喊多时往往最危险

---

## 4. 第四阶段：下跌 → 空仓或做空

**特征**
- 价格压在关键均线（尤其 30 / 40 周）下方
- 空头排列或均线向下
- 2022 年通胀熊市即典型第四阶段

**动作**
- 不做多，可空仓或按体系做空
- 等跌透后进入第一阶段筑底，再重复循环

## 5. 扫描器用法

```bash
cd four_stage_cycle
python3 scanner.py --data-dir ./sample_data          # 全池扫描
python3 scanner.py --data-dir ./sample_data --phase 2  # 只看第二阶段（做多候选）
python3 scanner.py --data-dir ./sample_data --json
```

**更新数据（Cursor + Longbridge MCP）**
1. 对每个标的调用 `candlesticks`，`period=week`，`count=200`
2. 保存为 `sample_data/<symbol>.json`
3. 或：`python3 fetch_data.py --stdin` 批量写入

## 7. 每日检查清单

1. 打开标的**周线图**，心算或跑 `scanner.py`
2. 当前是第几阶段？对应动作是什么？
3. 若第二阶段：排列是否仍完整？有没有贴近十周线？
4. 若第三阶段：有没有「利好不涨」、十周线反复被拒？
5. 若第一阶段：有没有放量突破 + 均线收复的**转阶段**迹象？

**铁律：没进入第二阶段，就不做多。**
