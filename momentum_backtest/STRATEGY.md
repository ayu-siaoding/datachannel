# 30分钟上涨 → 持有2–3天：可检验交易规则

> 仅供方法验证与学习，不构成投资建议。下列数字来自 20 只 A 股样本、约 2026-02-27 ~ 2026-08-10 的粗略回测。

## 1. 把模糊想法变成规则

| 模块 | 裸追版（原想法） | 规则版 B（相对更稳） |
|------|------------------|----------------------|
| 入场信号 | 单根 30m 涨幅 ≥ 1.5% | 30m 涨幅 ≥ 2%，且成交量 ≥ 近20根均量的 2 倍 |
| 过滤 | 无 | 当日累计涨幅 ≤ 6%；收盘价在日线 MA20 之上 |
| 买入价 | 信号下一根 30m 开盘 | 同左 |
| 止损 | 无 | −3%（按后续 K 线最低价触及） |
| 止盈 | 无 | +8% |
| 时间退出 | 持有满 2 或 3 个交易日收盘 | 持有满 2 个交易日收盘 |
| 仓位 | 未定义 | 每天最多 1–2 只新开仓；单笔 25%–30% 资金 |
| 成本 | 回测按双边合计 0.15% | 同左 |

## 2. 回测结论（重点）

### 单笔统计（每只股票信号都做，偏乐观）

- 裸追持有 2 日：胜率约 49%，**中位数收益为负**，交易序列最大回撤可到 **-90% 量级**。
- 规则版 B：平均单笔看起来更好，回撤明显下降，但仍不是稳定边沿。

### 更接近实盘的组合层（每天限信号 + 固定仓位）

| 方案 | 组合收益 | 最大回撤 | 评价 |
|------|----------|----------|------|
| 裸追 / 每天最多2只 / 各25% / 持2日 | +4.7% | **-50.6%** | 几乎不划算 |
| 规则B / 每天最多2只 / 各25% | +23.7% | -9.8% | 样本内最好，但月份波动大 |
| 规则A / 每天1只 / 50%仓 / 持3日 | **-22.3%** | -26.4% | 仓位过重 + 持有过久易亏 |
| 规则B / 每天1只 / 30%仓 | -5.5% | -12.2% | 一改参数就翻脸 |

分月看：有的月份赚、有的月份明显亏（例如裸追在 2026-07 平均单笔约 -5%）。  
同期样本股等权买入持有约 **+12%**，而裸追组合只有约 **+4.7%** 却承受 **-50%** 回撤——说明“追30分钟涨”未必跑赢简单持有。

**这说明：不是“长期印钞”，而是强依赖市场状态与参数。**

## 3. 实操清单（若要用规则版 B 做小资金验证）

1. 只在日线 MA20 上方找票。
2. 盘中出现 30 分钟实体涨幅 ≥ 2%，且该棒明显放量（≥2×近20棒均量）。
3. 当天从开盘算起涨幅还没超过 6%（避免末段接力）。
4. 下一根 30m 开盘买；跌破成本 −3% 走；涨到 +8% 走；否则第 2 个交易日收盘走。
5. 每天新开仓不超过 2 只，总仓位留现金缓冲。
6. 连续亏损达到预设阈值（如一周净亏损 −5%）则停手一周，复盘后再开。

## 4. 长期能不能赚钱？

在本样本下的诚实答案：

- **裸追 30 分钟上涨再拿 2–3 天：不适合当长期主策略。** 期望值不稳定，回撤过大。
- **加过滤 + 止损止盈后，样本内可以做出正期望的样子，但对参数和选股池很敏感；换“每天只做最强 1 只”就可能转负。**
- 要证明“长期赚钱”，至少还需要：全市场或更大股票池、跨牛熊年份、样本外实盘小仓、计入涨跌停/滑点无法成交。
