## 可落地粗筛 Checklist

```
□ 题材周期 = 爆发期（连板≥2 或 20日强势+涨停）
□ 涨停基因 ≥ 2/3：历史连板 + 换手5-15% + 流通盘20-200亿
□ 事件催化 ≥ 1：业绩预增/中标/政策/重组/涨价
□ CANSLIM：业绩+筹码+龙头+量价突破（full 模式）
□ 大盘非 bear + 市场题材非退潮期
□ 人工复核：新故事逻辑、板块地位、资金面
```

## 实战提醒

1. **只在爆发期参与**，退潮期再好的票也容易被埋
2. **永远买龙头**：板块内第一个涨停、第一个创新高
3. **涨停基因**：股性活、换手充分，流通盘适中
4. **事件催化**是爆发力关键：无新故事难走连续大阳线
5. **-8% 无条件止损**（O'Neil 铁律）
