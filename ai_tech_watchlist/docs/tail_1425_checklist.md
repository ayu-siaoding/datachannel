# A 股尾盘 14:25 检查清单

> **方法来源：** 3880 大盘点位 + 资金柱/主力净流入 + 筹码分布 + 15 分钟站稳（颖姐体系 + Brooks 尾盘战法）  
> **适用：** 机动仓 30%，T+1 隔天卖  
> **使用时间：** 每个交易日 **14:25～14:50**

---

## 一、14:25 大盘三门（不过 = 今天不买）

| # | 检查项 | 标准 | ✓ |
|---|--------|------|---|
| 1 | **上证 vs 3880** | 现价 **≥ 3880**；在 3875～3880 晃 → 仓位减半；**< 3875** → 停买 | ☐ |
| 2 | **成交额** | 全日成交向 **2.3 万亿**靠拢且指数不跌；**< 2 万亿缩量** → 谨慎 | ☐ |
| 3 | **资金柱 / 卖力道** | 绿柱不放大、卖力道不强；大盘急杀 → 停买 | ☐ |

**大盘备注（今日填）：** 上证 ______ 点 · 成交额 ______ 万亿

---

## 二、14:25 个股五门（每只候选都要过）

| # | 检查项 | 标准 | ✓ |
|---|--------|------|---|
| 1 | **主力净流入** | 通达信 **主力净额 > 0**，且 **> 5000 万**（大票 > 1 亿更佳） | ☐ |
| 2 | **价涨配合** | 涨幅 **+0.5%～+4%**；**涨停 / >+6%** 不追 | ☐ |
| 3 | **流入但不涨** | 主力进但价跌或横盘滞涨（如金风）→ **剔除** | ☐ |
| 4 | **筹码** | 上方 **无新厚套牢峰**；低位筹码 **未大量上移** | ☐ |
| 5 | **15 分钟站稳** | 14:00 后 **低点抬高** + 最后一根 **小阳/下影** + 价在 **14:00 后低点上方** | ☐ |

## 三、14:30～14:50 执行表

```
14:25  填完上一、二节；从观察池选 1～2 只
14:30  看 15 分 K：是否继续站稳？
       ├─ 否 → 换另一只或空仓
       └─ 是 → 进入 14:45 买入区
14:45  下单（记录：代码 / 买入价 / 止损价）
14:50  截止下单
```

## 四、止损与隔天卖

| 类型 | 规则 |
|------|------|
| **止损** | 买入日 **14:00 后 15 分低点** 或 **当日最低价**（取较高者） |
| **隔天目标** | **+2%～+3%** 减仓；到 **+4%** 至少减半 |
| **隔天强制走** | 破 **买入日最低价**；或大盘 **有效跌破 3880** |
| **Brooks** | 第一次回落可 hold；**第二次回落** 或到目标 → 走 |

---

## 五、一票否决（出现任一条 = 不买）

- [ ] 上证有效跌破 **3880**（收盘前仍站不回）
- [ ] 个股 **主力净流出**
- [ ] 涨幅 **> 6%** 或 **涨停**
- [ ] 15 分 **14:00 后仍创新低**
- [ ] 筹码 **高位密集 + 放量滞涨**
- [ ] ST / 极小盘 / 换手 **> 15%** 题材妖股
