# A股龙虎榜 / 游资席位 / 涨跌停博弈 跟踪工具

面向短线交易的数据分析小工具，重点解决三件事：

1. **龙虎榜个股扫描**：谁上榜、净买多少、上榜原因是什么  
2. **席位画像**：游资 / 机构 / 北向 / 量化 自动打标  
3. **涨跌停博弈评分**：按“机构承接 + 游资结构 + 换手/振幅”给出跟踪建议  

> 美股没有 A 股式龙虎榜与涨跌停，跟踪逻辑不同（13F、暗池、大单异动、热度榜）。本目录以 A 股为核心，美股书单与数据源见下方清单。

## 快速开始

```bash
cd dragon_tiger
pip install -r requirements.txt
python cli.py --date 20260810 --top 15 --json-out data/out/20260810.json
```

说明：
- 龙虎榜通常在**交易日收盘后**由交易所披露，盘中跑当日日期可能为空，请用上一交易日。
- `--top` 控制抓取席位明细的股票数（避免请求过多）。

## A股使用方法（推荐工作流）

1. 收盘后跑 `cli.py --date YYYYMMDD`  
2. 先看 **重点跟踪 / 观察** 清单  
3. 再点开 JSON，核对席位明细（是否机构+游资共振）  
4. 次日开盘结合 TDX：成交额、主力净额、30分钟结构再决定是否介入  
5. 连续跟踪同一游资席位：是否在主线龙头上反复出现

### 涨跌停博弈速记

| 结构 | 含义 | 处理 |
|------|------|------|
| 机构净买 + 游资净买 | 承接较好 | 可观察/轻仓 |
| 纯游资堆买、机构卖 | 博弈强、容错低 | 谨慎，高位回避 |
| 北向大买 + 振幅榜 | 波动博弈 | 控制仓位 |
| 跌幅榜 + 机构接盘 | 超跌反抽候选 | 不追高，等止跌 |
| 换手>30% 且净买弱 | 兑现风险 | 回避 |

## 与通达信 MCP 的配合

- **盘中**：用 TDX MCP 看实时涨跌、主力净额、均线/MACD、30分钟结构  
- **盘后**：用本工具看龙虎榜席位结构与游资路径  
- 二者结合：TDX 负责“价量资金实时”，本工具负责“谁在买、怎么博弈”
