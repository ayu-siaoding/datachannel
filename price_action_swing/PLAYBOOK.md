# Al Brooks 价格行为波段手册

> 参考：[【价格行为学】踏上交易之路(4): 止损(中)](https://youtu.be/a3XBfMSRC0E) — 方方土 PriceAction  
> 方法来源：Al Brooks 价格行为学，适配 A 股 T+1 与日 K 波段（3–15 日）  
> **不构成投资建议**

## 核心理念

止损不是「亏多少砍仓」，而是**交易管理**的一部分：

1. **背景**（Always In 方向 + 市场周期）
2. **位置**（支撑/阻力、EMA20、区间边界）
3. **信号 K**（收盘靠近极值的有实体 K 线）
4. **跟随**（突破后是否被接受）
5. **结构止损**（放在假设失效处，而非固定百分比）
6. **波段管理**（测量移动目标 + 移动止损保护利润）

---

## 1. 市场背景（先做这一步）

| 状态 | 识别 | 波段动作 |
|------|------|----------|
| Always In 多 | 更高低点 + 收盘 > EMA20 + 回调不破结构 | 只找 H2 回调买 |
| 窄/宽通道 | 沿 EMA20 运行，回调 1–2 段 | H2 入场，止损在回调低点 |
| 震荡区间 | 价格围绕 EMA20 来回 | 只在区间底部 H3，**中部禁止** |
| Always In 空 | 更低高点 + 收盘 < EMA20 | **不做多** |

**80% 法则：** 震荡区间里 80% 突破会失败 → 不要在中部追突破。

---

## 2. 入场：数 K 线 + 信号 K

### 2.1 顺势回调（最常用）

在多头通道/趋势中，回调结束后数「试图恢复上涨」的次数：

| 标记 | 含义 | 波段建议 |
|------|------|----------|
| H1 | 第一次 push up | 观察，不追（常失败） |
| **H2** | 第二次 push up | **最佳波段入场** |
| H3 | 第三次 push up | 震荡区间底部可用 |

**信号 K 条件（做多）：**
- 阳线，实体 > 45% 振幅
- 收盘在 K 线区间 upper 55% 以上
- 入场：信号 K 高点上方（A 股用**收盘确认**，次日开盘成交）

### 2.2 两段式回调（ABC / TBTL）

强突破后常见 **A 腿跌 → B 腿弹 → C 腿再跌**，C 腿结束出现 H2 信号 K → 高胜率波段点。

---

## 3. 结构止损（视频核心）

### 3.1 初始止损

| 场景 | 止损位置 |
|------|----------|
| H2 趋势买 | 回调最低点（pullback low）下方 |
| 信号 K 买 | 信号 K 低点与结构低点取较低 |
| 强趋势 | 可跟踪 EMA20，但 A 股默认仍用结构低点 |

**禁止：** 没有结构依据的固定 -3% 止损（仅作 A 股情景风险上限）。

### 3.2 实际风险 vs 初始风险

- **初始风险** = 入场 − 初始止损
- **实际风险** = 若已移动止损，按当前止损重算
- 仓位 = 账户风险预算 ÷ **实际风险**（每股）

### 3.3 移动止损 / 保护利润

| 阶段 | 动作 |
|------|------|
| 浮盈 ≥ 1R | 止损移至入场价（打平） |
| 浮盈 ≥ 2R | 止损移至最近更高低点下方 |
| 接近测量移动目标 | 先减半，余仓跟踪 |
| 出现反向信号 K + 跟随 | 提前离场（视频强调「提前保护利润」） |

---

## 4. 目标位

1. **最小目标：** 2R（两倍实际风险）
2. **前高：** 最近 swing high
3. **测量移动（Measure Move）：** 第一腿长度投射第二腿

---

## 5. 波段 vs 剥头皮

| | 波段 | 剥头皮 |
|---|------|--------|
| 持有 | 3–15 日 | 1–3 日 |
| 目标 | 2R ~ 测量移动 | 1R 左右 |
| 入场 | **H2** 优先 | H1 也可 |
| 背景 | 必须有趋势/通道 | 震荡也可 |

视频案例：沪锡「没有波段，只能剥头皮」→ 背景不对时**不要强行波段**。

---

## 6. A 股执行适配

| 规则 | 说明 |
|------|------|
| T+1 | 信号 K **收盘确认**，次日开盘买；当日仅观察 |
| 涨跌停 | 止损价需可成交；涨停无法买则放弃 |
| 尾盘 | 14:30 后不出新信号，等收盘 |
| 情景风险 | 初始风险 > 6% 则放弃或减半仓 |
| 不加仓摊平 | 止损 = 假设错误，不是「再等等」 |

---

## 7. 六步决策链（每笔必走）

```
背景 OK? → 位置 OK? → 信号 K? → 跟随确认? → 结构止损+仓位 → 写入管理计划
   ↓否         ↓否        ↓否         ↓否              ↓
  空仓        观望       观望        观望            放弃
```

---

## 8. 日常流程（收盘后 15 分钟）

1. 510300 背景：Always In？周期？
2. 扫描池：有无 H2 + 信号 K？
3. 计算结构止损 → `position_sizer.py` 反推仓位
4. 写交易计划：入场/止损/2R目标/移动止损规则
5. 无合格信号 → **空仓**（正常）

## 10. 40–60 定律

约 40–60% 交易会止损出场，这是正常的。关键是：
- 止损小（结构清晰）
- 盈利单拿住（移动止损）
- 不在错误背景交易
