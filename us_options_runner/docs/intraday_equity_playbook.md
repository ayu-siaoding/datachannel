# 大票日内正股 · 开盘前筛选 + 执行表

> **定位**：70/30 体系里 **30% 机动仓 · 日内正股**（不是底仓，不是 0DTE）。  
> **你的参数**：股价 **≥ $300**，一次 **~40 股**，目标 **+$100～150/单**。

配置：`config/intraday_equity.yaml`

---

## 一、开盘前 3 条筛选（必须全过）

### 筛选 1 · 大票 + 流动性

| 检查项 | 标准 | 在哪看 |
|--------|------|--------|
| 股价 | **≥ $300** | 报价 / Longbridge `quote` |
| 成交额 | 越大越好，优先 **META AMZN GOOGL NVDA TSLA** | App 成交额 |
| 价差 | 买一卖一差小 | Level-1 盘口 |

**Longbridge MCP（Agent 可说「筛大票」）**

```text
screener_search: market=US, prevclose min=300, sort=prevchg desc
再 intersect watchlist tier1
```

---

### 筛选 2 · 当天有利好（catalyst）

| 检查项 | 标准 | 在哪看 |
|--------|------|--------|
| 新闻 | 财报 / 评级 / 行业 / 公司公告 | App **资讯** / `news_search` |
| 预盘涨跌 | **-2% ~ +3%** 可观察 | 预盘报价 |
| 别追太高 | 已 **+4%** 以上 → **只等回踩**，不追第一根 | 分时 |

**过线**：能一句话说清 **「今天为什么可能涨」**。

---

### 筛选 3 · 主力净流入

| 检查项 | 标准 | 在哪看 |
|--------|------|--------|
| 主力 | **净流入为正** | App：**个股 → 资金 → 主力** |
| 趋势 | 近 **30～60 分钟** 流入在 **加速或维持** | 资金分时 |
| 别被骗 | 大涨 + 流入 → **等 9:45 后回踩**，不 9:31 追 | 1 分钟 K |

**Longbridge MCP**

```text
capital_flow symbol=AMZN.US  （看 net 是否改善）
```

---

### 筛完以后

- 观察池 **最多 2 只**，且必须在 **tier1/tier2 熟悉名单** 里。  
- **三条不过 → 今天不做**，比强行交易强。

## 四、Longbridge App 操作路径

1. **选股**：市场 → 美股 → 筛选 → 价格 >300 → 按涨跌幅 / 成交额排序  
2. **看资金**：点个股 → **资金** → **主力净流入**、大单  
3. **看新闻**：个股 → **资讯** → 当天标题  
4. **下单**：1 分钟 K + 分时均线 → 限价单 40 股

## 七、常见问题

**Q：主力流入但股价跌？**  
可能是出货伪装。要 **价在均线上方 + 流入** 一起做；否则不做。

**Q：和「开盘 3 分钟就买」？**  
改为 **9:45 后回踩**；流动性仍然好，假突破少很多。

**Q：账户 < $25k？**  
注意 **PDT**：5 个交易日内 >3 次日内往返可能受限。

**Q：赚 $100 就卖还是贪？**  
**到了 +0.8%～1.2% 先卖**；日内不靠一单暴富。
