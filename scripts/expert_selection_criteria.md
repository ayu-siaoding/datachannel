# 专家选股评判标准（白话版）

> **用途**：后续凡问「能不能买 / 买哪只 / 仓位多大」，一律先对照本文判定。  
> **地位**：专家意见与执行纪律；与 `Stock selection expert skills.md`、`select_rules_3hao.md`、中证800 开关并行，**冲突时以本文「硬否决」为准**。  
> **来源**：上证大盘趋势分析手记（先机 / 趋势 / 量能 / 全仓 / 宜小不宜大）+ 永泉·蔡森·KDJ·鸟叔钟摆 + 三好打分。

---

## 总原则（一句话）

先问大盘「能不能做、做多大」，再问个股「该不该碰、挂多少钱」。  
大盘说宜小，涨幅榜再热闹也当噪音。

---

## 第一步：大盘打表（每天必做）

只答 **是 / 否 / 不清楚**。不清楚按 **否**。

| # | 问题 | 怎么判 | 否 → 动作 |
|---|------|--------|-----------|
| 1 | **有没有先机？** | 情绪偏怕、结构刚从低位起来才算有；情绪不好 / 看不到早段机会 = 无 | **不新开主仓** |
| 2 | **趋势客观好吗？** | 方向清楚且能量配合才算好；「看着有勾但资金在跑 / 方向不客观」= **假强，算差** | **只做小周期，不接力** |
| 3 | **量够不够？** | 近月有没有像样放量支撑趋势；长期量不足（如连续多月未达成）= 不够 | **不信大涨，不加杠杆** |
| 4 | **能不能全仓？** | 上面 1～3 有一项为否 → **全仓 = 无** | 总仓只宜小 |
| 5 | **加减仓指令？** | 先机无 或 趋势差 或 量不够 → **宜小不宜大** | 小仓 / 只挂限价 / 不追涨 |

### 大盘输出 → 仓位开关（对齐中证800）

| 打表结论 | 对应开关 | 允许动作 |
|----------|----------|----------|
| 先机有 + 趋势好 + 量够 + 判断客观 | **布局** | 可分批建仓（仍过个股关卡） |
| 先机无 / 趋势差 / 量不够 / 全仓无 | **精选** | 池内回踩限价，宜小不宜大 |
| 情绪狂热或宽基高位失控 | **减仓** | 减仓持币，不新开 |

### 打表假通过（必须当否）

- 格子打了 ✓，但旁注 **「方向不客观」「资金在跑」** → 记为 **×**
- 标记为 **?**（不明是非）→ 记为 **否**
- **妖股先起、宽基无先机** → 投机市，**不跟涨幅榜**

### 每日一页（照填）

```
日期：____
先机：有 / 无
趋势：好 / 差 / 观察（有「不客观」则改差）
量能：达成 / 不足
全仓：有 / 无
加减仓：宜小 / 可加
今日只做：空手 / 池内挂L2 /（禁止：涨幅榜追入）
观学点：________________
```

## 第二步：个股关卡（大盘过了才看）

**一关不过就不买。** 顺序固定。

| 关卡 | 白话规则 | 硬否决 |
|------|----------|--------|
| 1 **在池子里** | 必须在观察池 / 扫描宇宙内 | 不在池 → 不买（涨再多也不买） |
| 2 **不追大阳** | 当日涨幅 **≤ +3%** | 单日 **>+3%** → 不追（可等回踩再议） |
| 3 **J 不过热** | 日线 KDJ **J ≤ 85** | **J > 85** → 不追 |
| 4 **三好** | 量好 · 题材好 · 板块好（见 `select_rules_3hao.md`） | 缺 **2** 项 → 不买；缺 **1** 项 → 最多观察 |
| 5 **限价买入** | 不市价追；挂 L1 / L2 / L3，优先 **L2** | 禁止涨幅榜市价扫货 |
| 6 **仓位上限** | 单只 ≤ 总资金 **20%**；光+存储主题合计 ≤ **40%**；与平安/红利等分桶 | 超限先降再谈加仓 |

### 限价档（A股默认）

- **L1**：现价附近浅回踩（约 -1.5%）  
- **L2**：更深回踩（约 -4%）← **精选期优先挂这档**  
- **L3**：更深/近 MA20 一带  

美股同理：回踩挂限价，不追当日大阳。

## 第三步：怎么下结论（评判话术）

回答「可以买哪只」时，必须按此结构：

1. **大盘一句**：先机/趋势/量/全仓/加减仓 → 布局 | 精选 | 减仓  
2. **名单筛选**：列出被硬否决的（>+3%、J>85、不在池、三好缺二等）  
3. **可挂标的**：仅输出过关者 + L1/L2/L3 + 建议仓位（宜小则注明）  
4. **禁止句**：涨幅榜、荐标、妖股行，在精选/减仓期默认 **全否**，除非回落后重新过关  

若大盘为 **精选 + 宜小不宜大**：  
- 允许：池内缩量回踩、J 低位、三好尚可 → **挂 L2**  
- 禁止：热股榜一日游、题材对但大阳（如 AI 安全大涨日）

## 口诀（背这三句）

1. **先机没有、趋势差、量不够 → 宜小不宜大。**  
2. **池子里的、没涨超 3% 的、J 没爆的、三好过关的 → 挂低买。**  
3. **榜上红彤彤的、荐标、不在池的 → 一律当没有。**
