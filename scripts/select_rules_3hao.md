# 选股三好：量好 · 题材好 · 板块好

与永泉/蔡森/KDJ、中证800开关、不追大阳并行。  
脚本：`screen_us_tonight.py` / `screen_ashare_tonight.py` 已打分输出。

## 定义（可执行）

| 维度 | 好的标准 | 否决/降权 |
|------|----------|-----------|
| **量好** | 相对量 rvol≥1.2；温和上涨放量；或缩量回踩后量能未溃散 | 放量大阳（>+3%且放量）不追；暴跌巨量先等企稳 |
| **题材好** | 有清晰兑现链：光/OCS/存、AI安全、电力设备、红利防御等；能写清「谁付钱」 | 纯故事、无订单/无利润路径；与全仓主题重复叠加 |
| **板块好** | 对应板块 ETF/指数近 5 日相对大盘（SPY 或中证800）走强或至少不弱 | 板块连续弱于大盘仍追个股；宽基「减仓」时板块再强也只小仓 |

## 与仓位开关

1. 先看 **中证800 / SPY** 温度（布局/精选/减仓）。  
2. 再看 **板块好**（行业相对强弱）。  
3. 个股同时满足：**题材标签 + 量好 + KDJ/限价纪律**。  
4. 三好里缺一：最多「观察」；缺二：不买。

## 输出字段

扫描结果中的 `量/题材/板块` 三档（好/中/弱）与加分，见每日 `*_tonight_latest.md`。
