# A股 OCS（光学电路交换机）对照表

对应美股叙事：**Lumentum / Coherent**（整机外采）+ 谷歌 MEMS 主导。  
国内多为 **器件 / 代工 / 验证**，营收贡献大多仍早期；**概念 ≠ 订单**。

## 产业链分层（与 LITE/COHR 对齐）

| 层级 | 对应海外 | A股优先关注 | 说明 |
|------|----------|-------------|------|
| MEMS 芯片/振镜 | 谷歌自研指定 + 代工 | **赛微电子 300456**、**英唐智控 300131** | MEMS 仍是商用主路径 |
| 光学件（准直/滤光/阵列） | OCS BOM 高价值量 | **腾景科技 688195**、**天孚通信 300394** | 准直器/阵列等；跟放量弹性 |
| OCS 整机/代工 | **LITE / COHR** | **光库科技 300620**（收购捷普）、**光迅科技 002281** | 光迅有 MEMS OCS、客户验证；光库有代工能力（谷歌供应链勿当事实） |
| 硅光/其他路线 | iPronics 等 | **德科立 688205**、旭创/新易盛（布局） | 德科立曾公告：**未来 2～3 年营收规划未计入硅基 OCS** |
| 下游交换机/方案 | 数据中心网络 | 紫光股份、锐捷网络 | 偏方案，OCS 弹性弱于器件 |

国信等研报常点名：**中际旭创、光迅科技**（产业位置清晰，不等于短期能买）。
