# 完美入场框架（技术发现 → AI 验证 → 四条件开仓）

> **主文档已归档至**：[`技术分析/完美入场四条件.md`](../技术分析/完美入场四条件.md)

> 来源：用户提供的投研思路截图。与 **9:20 短线题材扫描** 配合使用：前者负责「技术发现候选」，本文负责「是否值得开新仓」。

## 一、流程（不要技术一发现就下结论）

```text
技术发现一家公司
    ↓
立刻用 AI / 工具做第二层分析（不急于交易）
    ↓
判断：情绪 / 业绩 / 产业拐点，谁在驱动？
    ↓
四项全部清晰 → 才开新仓
    ↓
平时只训练这种思维，耐心等完美机会
```

## 二、第二层必须看的六类信息

| 维度 | 要问什么 |
|------|----------|
| **基本面** | 营收/利润趋势、负债、现金流、商业模式是否站得住 |
| **消息面** | 近期催化是真利好还是纯情绪？有无监管/减持/业绩雷 |
| **近一个月资金流入** | 主力/北向/板块是否**持续**净流入，还是单日脉冲 |
| **机构持仓** | 基金/社保/QFII 等是否在增配或至少稳定 |
| **市场研报** | 一致预期、目标价区间、核心假设是否仍成立 |
| **估值是否合理** | PE/PB/PEG 相对自身历史与同业，是否透支 |

## 三、驱动类型（三选一或组合）

- **情绪推动**：题材、事件、短线共识（与 `short-theme` 扫描高度相关）
- **业绩推动**：财报、订单、毛利率等可验证数据
- **产业拐点**：行业渗透率、政策、供需周期进入上行段

开新仓前写一句：**当前主要是哪一种？** 若只有情绪、无业绩与产业支撑，小资金应降低仓位或只做短线。

## 四、开新仓公式（四项同时满足）

```text
技术信号 + 资金流入 + 估值合理 + 产业向上发展期
```

| 条件 | 短线题材（9:20 扫描） | 第二层（本框架） |
|------|-------------------------|------------------|
| 技术信号 | 溢价、龙/中军、梯队 | 趋势/结构是否仍健康 |
| 资金流入 | 竞价与同题材集中度 | **近 1 月** 净流入、机构动向 |
| 估值合理 | （脚本暂不评） | 人工 + AI 查研报/财务 |
| 产业向上 | 主题排名、非一日游 | 行业景气、政策与产业链数据 |

**任一项不清晰 → 不开新仓，只观察。**

## 五、与 `premarket_scan.py` 的分工

| 时间 | 动作 |
|------|------|
| **09:20** | `daily_codes.sh` → `outputs/codes_YYYYMMDD.txt`（技术发现候选，排除北交所） |
| **09:20～09:30** | 对候选逐只问 AI（或查 F10/研报）：六类信息 + 驱动类型 |
| **09:30 后** | 仅当 **四公式** 全过，才按 checklist 下单；否则放弃 |

## 六、给 AI 的固定提问模板（复制即用）

```text
股票：{代码} {名称}
请基于公开信息分析：
1）基本面要点与主要风险
2）近一个月消息面与资金流入特征
3）机构持仓变化（若有季报数据）
4）研报一致预期与估值是否合理
5）主导驱动是情绪/业绩/产业拐点中的哪一种？
6）是否同时满足：技术信号+资金流入+估值合理+产业向上？缺哪一项？
仅作研究参考，不构成投资建议。
```

## 七、小资金提醒

- 9:20 列表是 **「值得看」**，不是 **「必须买」**。
- 完美入场 = **少做很多次**，不是 **每天都做**。
- 情绪单：严格仓位与隔日纪律；产业+业绩单：可略放长一点持有周期。

非投资建议。
