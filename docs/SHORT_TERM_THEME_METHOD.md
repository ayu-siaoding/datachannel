# A 股短线题材方法（开盘前 10 分钟）

> **方法来源（用户提供）**：[X 视频帖](https://x.com/cj3214567667/status/2114717684827037856/video/1)  
> 自动化实现：`scripts/premarket_scan.py`（`--method short-theme`）  
> 说明：视频为第三方分享，本仓库仅将**可量化的盘面规则**落地为脚本；无法播放视频时，以用户确认的文字规则为准。

## 一、适用范围

- **短线题材**，不做北交所（`8` / `920` 等）。
- 标的池：沪深主板 + 创业板 + 科创板，**排除 ST**。
- 默认运行时刻：**09:20（Asia/Shanghai）**，即开盘前约 10 分钟。

## 二、核心原则（与视频/口述一致）

1. **主线 ≠ 今天涨幅最大的板块**  
   今日竞价涨幅榜首多为末期扩散或一日游，**不能**自动当作主线。

2. **持续性题材**  
   从**少数核心股**起步 → 板块效应 → 资金共识 → 合力；**不在行情尾声**接最后一棒。

3. **同一根放量突破阳线**  
   出现在**主线核心**上有延续意义；出现在杂毛/多概念蹭票上多为卖点。

4. **分化后的回流顺序**  
   **空间龙 → 中军 → 带板块效应的补涨**（同概念至少 3 只跟涨）。

5. **昨日涨停 → 今日溢价**  
   核心应**高开且能走强**；跟风常**高开 ≥7% 后翻绿**，一律不追。

## 三、盘前 10 分钟必做（人工 + 脚本）

| 步骤 | 动作 | 脚本字段 |
|------|------|----------|
| 1 | 昨涨停池（非北交所） | `昨涨停数量_过滤后` |
| 2 | 竞价溢价（核心是否认账） | `昨日涨停溢价` |
| 3 | 主题集中（连板梯队 + 家数） | `主题排名`、`主题材` |
| 4 | 角色分工 | `角色.空间龙 / 中军 / 补涨` |
| 5 | 合并观察代码 | `观察池代码` |
| 6 | 非主线提示 | `今日竞价最强_非主线参考` |

## 四、可买 / 不买（relay 接力模式）

**可买（多数满足）**

- 主题在 `主题排名` 前列，且核心有 **竞价 ≥3%**（或数据缺失时保留角色池）。
- 位置：**1～3 板**或带板块的 **首/二板补涨**。
- **概念纯度**：脚本对「概念标签过多」的票降权（见 `concept_penalty`）。

**不买**

- 北交所、ST、无梯队单日脉冲。
- **连板 ≥6** 且 relay 模式（尾声）。
- 竞价 **高开 ≥7%** 的**非空间龙**（慎追）。
- `今日竞价最强_非主线参考` 中标的，**默认不进观察池**。

## 五、dragon 模式（龙头分歧回封）

- 只做**空间龙 / 中军**分歧，竞价 **≥ -3%** 仍可观察。
- 跟风深水、龙头跌停、板块全面退潮 → 不做。

## 六、与「完美入场四条件」衔接

9:20 脚本只做 **技术发现**（候选代码）。是否开新仓需再满足：

**技术信号 + 资金流入 + 估值合理 + 产业向上发展期**

详见 [`PERFECT_ENTRY_FRAMEWORK.md`](./PERFECT_ENTRY_FRAMEWORK.md)。

## 七、命令

```bash
./scripts/run_premarket.sh
METHOD=dragon ./scripts/run_premarket.sh
python3 scripts/premarket_scan.py --method short-theme --codes-only
```
