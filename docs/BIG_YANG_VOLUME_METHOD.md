# 第一根大阳线 + 放量：最优参数与用法

基于美股 46 只大盘股 / 近 5 年日线网格回测（960 组参数），以及 A 股约 34 只流动性标的对照。

## 结论（美股 · 利润最优）

| 项 | 规则 |
|---|---|
| 入场 | **第一根大阳线**：实体涨幅 ≥ **5%**，成交量 ≥ **MA20 的 2.5 倍**，收盘位于当日振幅上 **60%**，收盘 ≥ MA20，MA5 ≈≥ MA10 且短期不拐头向下 |
| 「第一根」 | 前一日不得同时满足「近似大阳 + 放量」 |
| 均线粘合 | **不要求**（强制粘合会降低期望） |
| MACD | **不强制**（美股最优组未开 MACD 过滤） |
| 出场（利润） | **止盈 +10% / 止损 −7%**，最长约 20 个交易日 |
| 样本表现 | n=47 · 胜率 **59.6%** · 期望 **+3.51%** · PF **2.56** · 均持仓 **7.6 日** · 20 日内摸到 +5% 概率 **81%** · 平均 MFE **20.3%** |

## 高胜率变体（同入场）

同一入场条件，改为 **止盈 +5% / 止损 −5%**：

- 胜率 **63.8%** · 期望 **+1.45%** · PF **1.88** · 均持仓 **3.9 日**

适合更短持仓、更在意胜率的场景。

## A 股对照（流动性池）

A 股最优附近组合更偏「更强放量 + MACD 水上红柱」：

| 项 | 规则 |
|---|---|
| 入场 | 实体 ≥ **4%**，量 ≥ **3.0× MA20**，收盘位置 ≥ 0.6，Close ≥ MA20，**DIF>0 且 MACD 柱>0** |
| 出场 | 优先 **TP +10% / SL −7%** |
| 参考表现 | n≈48 · 胜率 **62.5%** · 期望 **+2.98%** · PF **2.41** |

更极端的 `实体≥7% + 量≥3× + MACD` 期望更高，但样本偏少（n≈26），实盘信号稀少。

## 为什么不是「粘合第一根阳线」

此前「均线粘合 + 第一根阳」胜率约 51%–56%、期望偏弱。  
加入 **大实体 + 强放量** 后，胜率与期望同时抬升；网格里「强制粘合」多数劣于「趋势上方放量大阳」。

## 实盘纪律

1. **收盘确认后买**（或次日开盘弱开不追）。
2. 信号日若同时大面积普涨，仓位减半，避免主题拥挤一日游。
3. 止损优先执行：跌破入场日低点或触及 −7%（利润模式）立即离场。
4. 未触及止盈前，可用 MA10 跌破作为移动保护（可选，未计入上方统计）。
