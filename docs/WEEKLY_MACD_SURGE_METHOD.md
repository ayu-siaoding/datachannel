# 周K主升浪选股法（TSM 模板）

依据富途周线图标注固化：**价格主升斜线** 与 **MACD 绿柱持续** 同步出现；买点在主升前的 **回踩圆圈**；资金侧优先 **大单买 / 小单卖**。

参考图：TSM 周K 上用红斜线标主升段、用红横杠标 MACD 绿柱区间、用红圈标启动前低点。

## 一、图上在找什么

```
价格：  ／红斜线主升浪     ／又一波主升
       ●红圈低点          ●
MACD： ████ 绿柱持续      ████
```

| 元素 | 含义 | 选股规则 |
|------|------|----------|
| **周K 多头结构** | 长期上升通道 | 收盘 > 周 MA21，且 周 MA21 > 周 MA55 |
| **红斜线主升** | 一段加速上涨 | 近 8～20 周涨幅显著，且斜率陡于均线 |
| **MACD 绿柱横杠** | 动能持续为正 | DIF>0 且 MACD 柱（histogram）连续 ≥3 周为正 |
| **红圈低点** | 主升启动买点 | 启动前出现回踩周 MA21 / 前低，再放量向上 |
| **资金分布** | 大资金买、小资金卖 | 富途「超大单/大单净流入 + 小单净流出」；脚本用 CMF/吸收盘近似 |

---

## 二、标准流程（以后默认按这个找）

1. **周线过滤**：只做周线多头（价 > MA21 > MA55）。
2. **动能确认**：周 MACD **绿柱持续**（柱>0 且 DIF≥DEA 或刚金叉向上）。
3. **阶段判断**  
   - **启动区（优先）**：刚结束回踩（近 3～6 周有低点），本周/上周重新放量站上 MA21，绿柱转正或扩大 → **红圈买点**。  
   - **主升中**：绿柱已持续多周、价格沿斜线走 → 可持有，**不加在末端**.  
   - **警惕区**：价格创新高但绿柱缩短 / 顶背离 → 减仓，不追。
4. **资金确认**：大单净买、小单净卖（或 CMF5>0 + 吸收盘）。
5. **永泉风控**：分批；止损用回踩低点或周 MA21；目标 1:2；总仓受钟摆约束。

---

## 三、状态标签（脚本输出）

| 标签 | 含义 | 动作 |
|------|------|------|
| `dip_launch` | 红圈启动：回踩后绿柱转强 | **优先关注/分批买** |
| `surge_on` | 主升进行中，绿柱持续 | 持有或轻仓追突破 |
| `late_surge` | 涨幅过大 + 绿柱缩短 | 观望/减仓 |
| `reject` | 周线非多头或绿柱空 | 不做 |
